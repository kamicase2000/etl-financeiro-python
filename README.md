# 💾 API ETL & SQLite Pipeline

A robust Python script that acts as an ETL (Extract, Transform, Load) pipeline. It fetches real-time exchange rates via REST API, transforms product pricing, and persists the data into a local relational database using SQL.

## 🚀 Technologies Used
- **Python 3.x**
- **SQLite3** (Relational Database Management)
- **Requests Library** (REST API consumption)

## 🧠 What I Learned
During this build, I focused on:
- Designing database schemas and executing raw SQL queries (`CREATE`, `INSERT`, `SELECT`) within Python.
- Handling data persistence and connection states (`commit`, `close`).
- Structuring a basic ETL flow to mirror real-world corporate backend systems.
